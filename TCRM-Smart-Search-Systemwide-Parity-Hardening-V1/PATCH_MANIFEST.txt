TCRM-Smart-Search-Systemwide-Parity-Hardening-V1

GOAL
Bring TCRM local search bars up to the stronger TFCRM Smart Search UX pattern while preserving TCRM's stronger Global Search engine, role scope, adaptive ranking, Arabic/English normalization, and existing APIs.

SOURCE / TARGET
- Source reviewed: mohamedamouseo-a11y/TCRM-MAIN-Tamiyouz-CRM- (main + fix/smart-search-hardening-20260901)
- Reference: mohamedamouseo-a11y/TFCRM Smart Search Phase 3/4/5A/5B patterns
- Patch package target: mohamedamouseo-a11y/TCRM-main-patchs-

CORE CHANGES
1. Upgrade client/src/components/search/SmartSearchBar.tsx
   - backward-compatible string suggestions
   - rich {id,label,secondary} suggestions
   - custom dropdown/listbox
   - ArrowUp/ArrowDown/Enter/Escape keyboard support
   - Clear button
   - VoiceSearchButton
   - Arabic/English RTL handling
   - normalized 2-character suggestion threshold
   - compact mode and accessibility attributes

2. Harden Global Search
   - stale-request/request-order guard
   - old requests can no longer overwrite newer results
   - old finally() cannot incorrectly clear current loading state
   - visible bilingual error state instead of swallowed API failures
   - existing clients/deals/companies/contacts ranking + learning preserved

3. Harden server normalized exact search
   - escape !, %, and _ before SQL LIKE
   - use ESCAPE '!'
   - parameter binding remains intact

4. Improve Global BD search latency
   - Deals / Companies / Contacts independent search sections execute with Promise.all
   - existing BD ownership/access scope stays unchanged
   - exact-first bounded fuzzy behavior stays unchanged

AUDIT
AUDIT_SEARCHES.py performs a repository-wide inventory after application.
It distinguishes:
- SHARED Smart UI
- explicit Smart UI
- normalized/fuzzy logic with legacy UI
- plain/pending search UI

A search is NOT considered migrated merely because a fuzzy/normalized matcher exists.

SAFETY
- NO DB migration
- NO schema change
- NO db:push
- NO role/permission expansion
- NO ownership-scope expansion
- NO TOS changes
- NO Evolution/WhatsApp sending behavior changes
- NO credential/autofill guard removal
- Existing pagination/filter/API source is preserved per screen.

Restart only the TCRM process(es) for the TCRM working directory if deploying to a server.

ROLLBACK
The apply script creates .smart-search-systemwide-v1.bak backups for modified existing files before writing changes.

IMPORTANT
The patch is source-only. It does not automatically build, restart services, modify the database, or change unrelated integrations.
