VISUAL REFERENCE CRITERIA — DESKTOP 1920x1080
The result should visibly match these characteristics:
- Sidebar width stays around the existing 240px expanded width.
- Light sidebar is pearl / very-light lavender, NOT a dark blue sidebar.
- Logo header is compact, clean and slightly separated from navigation.
- Collapse button sits visually inside the brand/header area, not awkwardly outside the panel.
- Top-level rows are compact (~36px), with restrained icons and balanced left/right padding.
- Current page row (Settings on the primary target) is a premium indigo/violet capsule with white text/icon.
- Expanded Sales group is a soft highlighted capsule even while Settings is the current page.
- Sales children are visually nested using a slim vertical connector/tree line and compact child rows.
- SLA badge remains visible and readable; no data/count changes.
- Navigation remains scrollable and no labels are clipped at 1920x1080.
- Bottom Admin/user block is a compact rounded card with avatar/name/role and a full-width subtle red Sign out button.
- No giant gaps, no oversized rows, no excessive neon/glow.
- Existing menu order, translations, permissions and destinations remain unchanged.
- Dark mode uses deep navy layered surfaces while retaining the same hierarchy and active indigo/violet treatment.
